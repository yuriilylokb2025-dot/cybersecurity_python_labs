# Лабораторна робота №2

## Тема
Розробка консольних утиліт для задач кібербезпеки.

## Варіант
Варіант 3 — Валідатор та аналізатор конфігурацій правил фаєрвола.

## 1. Встановлення залежностей

Перед запуском потрібно активувати віртуальне середовище з лабораторної роботи №1 та встановити залежності:

pip install -r requirements.txt

labs/

    ├── main.py

task1.py — модель користувача, адміністратора, сесії та журналу аудиту.

data/fw_audit_report.json — файл із очищеним списком правил після аналізу.

## 3. Завдання 1 — модель користувача та облікового запису

У task1.py реалізовано:

- клас User;
- клас Admin(User) із правами permissions;
- клас Session;
- клас AuditLog;
- AuditRecord через @dataclass;
- клас UserAccount;
- перевірку email через @property та re;
- хешування пароля через hashlib.pbkdf2_hmac("sha256", ...);
- випадкову salt через os.urandom();
- перевірку хешів через hmac.compare_digest();
- таймаут сесії;
- журналювання подій login_success, login_failure, logout.

### Запуск демонстрації

python -m labs.lab02.main demo

Демонстрація показує:

- успішний вхід;
- невдалий вхід;
- перевірку email;
- роботу прав адміністратора;
- завершення сесії за таймаутом;
- logout;
- записи AuditLog.

## 4. Завдання 2 — аналізатор правил фаєрвола

Програма читає правила з firewall_rules.json.

Для кожного правила використовуються поля:

- id;
- source;
- destination;
- port;
- action.

Реалізовано:

- перевірку IP-адрес і підмереж через регулярні вирази;
- пошук дубльованих правил;
- пошук конфліктних правил;
- виявлення небезпечних ALLOW-правил;
- використання collections.defaultdict для групування правил;
- журналювання через logging;
- збереження очищених правил у JSON-файл.

High-Risk правилом вважається ALLOW, якщо:

- source = 0.0.0.0/0;
- або port = ANY.

### Запуск аналізатора

python -m labs.lab02.main analyze --rules-file labs/lab02/data/firewall_rules.json --output labs/lab02/data/fw_audit_report.json --check-conflicts --log-level INFO

## 5. Параметри CLI

### demo

Запускає демонстрацію Завдання 1.

python -m labs.lab02.main demo

### analyze

Запускає аналіз правил фаєрвола.

Параметри:

- --rules-file — шлях до вхідного JSON-файлу з правилами;
- --output — шлях до вихідного JSON-файлу;
- --check-conflicts — увімкнути перевірку конфліктів і дублікатів;
- --log-level — рівень логування, за замовчуванням INFO.

## 6. Поведінка при помилках

Програма передбачає обробку некоректних ситуацій:

- якщо файл правил не існує — виникає FileNotFoundError;
- неправильний email викликає ValueError;
- невідомий ключ у UserAccount викликає KeyError;
- неправильний тип значення в UserAccount викликає TypeError;
- некоректні IP-адреси або підмережі позначаються як невалідні правила;
- неправильний логін або пароль фіксується як login_failure.
