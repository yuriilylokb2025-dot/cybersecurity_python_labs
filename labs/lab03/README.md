1. Мета роботи

Навчитися створювати Web API за допомогою FastAPI, працювати з базою даних SQLite, виконувати параметризовані SQL-запити, перевіряти дані через Pydantic та забезпечувати правильну обробку помилок і транзакцій.

2. Опис проєкту

Розроблено Web API для обліку навчальних результатів перевірки вразливостей робочих станцій.

Сервіс дозволяє:

* Створювати, переглядати та видаляти категорії.
* Додавати, переглядати, оновлювати та видаляти записи.
* Фільтрувати записи за категорією, статусом, оцінкою небезпеки та назвою.
* Виконувати пакетне створення записів.
* Перевіряти коректність вхідних даних.
* Обробляти HTTP-помилки.
* Забезпечувати атомарність транзакцій.

Параметри варіанта

* Категорії: os, browser, office.
* Одиниця вимірювання: score.
* Допустиме значення value: від 0 до 10.
* Поріг небезпеки: 8.0.
* Статуси: new, in_progress, done.

5. База даних

Використовується SQLite із двома таблицями.

categories:

* id — первинний ключ.
* name — унікальна назва категорії.

records:

* id — первинний ключ.
* code — унікальний код запису.
* title — назва знахідки.
* category_id — зовнішній ключ на categories.id.
* value — оцінка небезпеки.
* status — статус опрацювання.

Між таблицями реалізовано зв’язок «один до багатьох».

Для захисту даних використовуються параметризовані SQL-запити та обмеження PRIMARY KEY, FOREIGN KEY, UNIQUE, NOT NULL, CHECK.

6. Встановлення та запуск

Усі команди виконуються з кореневої папки репозиторію cybersecurity_python_labs.

Активація віртуального середовища (Windows PowerShell)

.\.venv\Scripts\Activate.ps1

Якщо середовище ще не створено:

python -m venv .venv
.\.venv\Scripts\Activate.ps1

Встановлення залежностей

python -m pip install -r requirements.txt

Необхідні пакети: fastapi, uvicorn, pydantic, ruff.

Створення бази даних

python -m labs.lab03.database

Заповнення початковими даними

python -m labs.lab03.seed

Під час першого запуску додаються три категорії та вісім записів.

Повторне заповнення непорожньої бази пропускається без створення дублікатів.

Запуск API

python -m uvicorn labs.lab03.main:app --reload --host 127.0.0.1 --port 8000

Після запуску доступні:

* Swagger UI: http://127.0.0.1:8000/docs
* OpenAPI: http://127.0.0.1:8000/openapi.json

7. HTTP-маршрути

Метод	Маршрут	Призначення
GET	/ping	Перевірка доступності
GET	/student	Дані студента
GET	/categories	Отримання категорій
POST	/categories	Створення категорії
DELETE	/categories/{category_id}	Видалення порожньої категорії
GET	/records	Отримання списку записів
GET	/records/{record_id}	Отримання запису за ID
POST	/records	Створення запису
PUT	/records/{record_id}	Повне оновлення запису
DELETE	/records/{record_id}	Видалення запису
POST	/records/bulk	Пакетне створення записів

Приклад створення запису

POST /records

{
  "code": "V03-TEST",
  "title": "Тестова вразливість Windows",
  "category_id": 1,
  "value": 8.7,
  "status": "new"
}

Успішна відповідь: 201 Created.

Приклад фільтрації

GET /records?category_id=1&status=new&min_value=8&limit=20&offset=0

Повертає записи категорії os зі статусом new та оцінкою небезпеки не менше 8.

Доступні параметри: category_id, status, min_value, q, limit, offset.

Приклад пакетного створення

POST /records/bulk

[
  {
    "code": "V03-BULK-01",
    "title": "Тестова вразливість браузера",
    "category_id": 2,
    "value": 6.5,
    "status": "new"
  },
  {
    "code": "V03-BULK-02",
    "title": "Тестова вразливість Office",
    "category_id": 3,
    "value": 7.8,
    "status": "in_progress"
  }
]

Успішна відповідь: 201 Created.

Пакет додається в межах однієї транзакції. Якщо виникає помилка, жоден новий запис із пакета не зберігається.

8. Обробка помилок

HTTP-код	Значення
200	Успішний запит
201	Ресурс створено
204	Успішне видалення без тіла відповіді
404	Запис або категорію не знайдено
409	Конфлікт унікальності чи обмеження зв’язків
422	Некоректні параметри або тіло запиту
500	Внутрішня помилка сервера
